# Dunia Peribahasa bersama Puteri Purut

1. Ekstrak ZIP ini.
2. Muat naik `index.html`, folder `assets` dan folder `videos` ke root repositori GitHub Pages.
3. Letakkan video MP4 dalam folder `videos` dengan nama `masa-itu-emas.mp4`, `berganding-bahu.mp4` dan `warisan.mp4`.
4. Commit changes dan buka laman web; tekan Ctrl+F5.

Peringkat 1 mempunyai tiga kad peribahasa, maksud dan audio. Peringkat 2 menggunakan ayat tepat yang diberi, video serta audio untuk setiap ayat. Peringkat 3 membiarkan ruang hasil kosong sehingga butang Jana Ayat atau Jana Cerita ditekan. Penjana menggunakan templat tempatan, bukan AI luaran.
